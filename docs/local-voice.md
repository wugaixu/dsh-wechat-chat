# 本地离线语音输入

鲸聊 1.3 起不再把录音发送给第三方语音平台，也不再把语音平台密钥编译进 APK。

## 数据流

1. Android 使用 `AudioRecord` 录制 16 kHz、16-bit、单声道 PCM。
2. 松开按钮后，App 在内存中生成标准 WAV（最长 60 秒，约 1.92 MB）。
3. App 使用当前 WebView 的公网登录 Cookie 和已配对设备凭据，把 WAV 以二进制上传到 `/api/wechat/voice/transcribe`。
4. 插件在电脑本机调用 whisper.cpp 的 multilingual small 模型离线转写。
5. 转写文字返回手机输入框；用户确认或修改后再发送到真实 DSH 会话。
6. 临时 WAV 和转写输出在任务结束后删除，默认不保留录音。

## 首次安装

在电脑本机打开 `http://127.0.0.1:3080/whale-panel`，点击「安装离线模型」。插件会下载：

- whisper.cpp Windows x64 CPU 运行库（约 8 MB）；
- multilingual small 模型（约 488 MB）。

下载地址和 SHA-256 固定在发布版本内；任何大小或哈希不符都会拒绝安装。文件安装到 `$DSH_HOME/wechat-chat/stt/`，不会进入 npm 包或 Git 仓库。

当前版本使用 CPU 运行库以减少依赖并兼容更多 Windows 电脑。模型会在每次语音转写时载入；短语音通常需要数秒。后续可增加常驻进程或 GPU 运行库。

## 安全限制

- 安装、状态和取消安装接口仅允许电脑回环地址访问；
- 公网语音上传必须通过鲸聊安全网关并携带有效设备凭据；
- 只接受 16 kHz、16-bit、单声道 PCM WAV；
- 最大请求 2.1 MB、最长 60 秒、全局单任务，并设置上传及识别超时；
- 运行程序、模型 URL、命令参数和临时文件名都由插件固定，客户端不能传入路径或命令行参数；
- App 禁止跳转到非配对 origin，公网请求不会跟随重定向，也不会记录 Cookie 或设备凭据。

## 故障排查

- 手机提示“请先安装离线语音模型”：打开电脑配对面板完成安装；
- 401：公网登录 Cookie 已失效，重新打开扫码地址并输入密码；
- 403：设备配对失效，重新扫码；
- 429：已有语音正在识别，稍后重试；
- 503：运行库或模型未安装完整；
- 504：本机识别超时，可缩短录音后重试。
